# Security policy

[中文](SECURITY.md)

## Supported versions

- `main` and the latest stable release receive security fixes.
- `develop` and preview releases accept reports and may be fixed with the next
  development release.
- Older releases are normally unsupported.

## Private reporting

Use **Report a vulnerability** on the repository Security page. Do not open a
public issue for credential exposure, unauthorized file access or overwrite,
command execution, private feedback or media exposure, or a bypass of source,
feedback-promotion, or release controls.

Include the affected version, reproduction steps, impact, and a suggested
direction if known. Remove real credentials and unnecessary personal data.
Maintainers will acknowledge the report and coordinate disclosure after an
initial assessment.
